## 2. 대화 갈래별 상태

각 갈래는 "사용자 질문 → 답변 요지 → 상태" 순이다. 숫자는 모두 `README.md`의 스모크 결과를 인용한 것이다.

### 2.1 여러 모델 평균이 단일 신경망보다 좋은 이유 — 답변 완료

- 전제 교정: 개선된 단일 신경망(MAE 12.12)은 단일 GBDT(12.26)보다 나빴던 것이 아니다. 앙상블(GBDT+NN 50:50 → 11.78, 합계 오차 11.88%)이 둘 다를 이긴 것이다.
- 오차 = 공통 성분(예보 오차, 돌발 요인) + 모델 고유 성분(편향·분산). 평균은 후자만 줄인다.
- 상관계수가 이득을 그대로 예측한다. 오차 크기가 비슷한 두 모델을 평균하면 표준편차는 √((1+ρ)/2)배. ρ=0.85 → 약 4% 감소. 실제 12.26→11.78은 3.9% 감소.
- 같은 계열끼리(GBDT–GBDT ρ 0.92~0.98)는 효과 없음. "여러 개"가 아니라 "귀납 편향이 다른 모델"이 핵심.
- 팀 합계 지표에서 이득이 더 큰 이유(12.89%→11.88%, −7.8%): 253개소 합계에서 발전소별 특이 오차는 상쇄되고, 남는 것은 모든 발전소가 공유하는 오차. 그중 모델의 체계적 편향은 계열마다 방향이 달라 평균하면 지워진다.
- 첫 NN의 14.08은 학습 설정(MSE, 40만 행 부분추출, 조기종료 없음) 문제. 단일 NN의 약점은 시드 분산(최대 0.23 kWh)이며 평균으로 지울 수 있다.
- 반대 근거: 임베딩 12.31→큰 네트워크 12.12의 개선 0.19는 시드 편차 안이라 "큰 네트워크가 낫다"는 미확립.

### 2.2 구성: 무작위 분할 vs 선별 분할 — 답변 완료, 재실험은 미결

| 구성 | 하한(한 팀) 대비 벌금 |
|---|---|
| 무작위 균형 분할 30회 평균 | +1.6% |
| 최적화(반년 최적화→나머지 반년 평가) | +1.3% |
| 참조 A/B | +2.2% |
| 동서 분할 | +7.9% |
| 남북 분할 | +11.8% |

- 0.3%p 차이는 기록된 수치로는 노이즈와 구분 불가. 이유 세 가지:
  1. **출발점 누수.** `experiments/comp_experiment.py:62-64`에서 국소탐색 출발점을 무작위 30개 중 "1년 전체 벌금" 최소로 고른다. 평가용 반년이 출발점 선택에 쓰였다. 30개 중 최솟값은 평균보다 약 2σ 낮으므로 무작위 산포가 0.15%p만 되어도 0.3%p 전부 설명된다. README는 30회 평균만 기록, 산포 미기록.
  2. 모델 하나·검증 연도 하나의 잔차. 48개소는 그 연도에 학습 이력이 없었다.
  3. 천장이 낮다. 초과분 전체 1.6% = 점수의 약 0.05%. 0.3%p = 점수의 약 0.01%.
- 실재하는 큰 효과: 지역으로 가르지 말 것(두 팀 오차 상관이 섞기만 해도 0.93).
- 권고: 층화 균형 분할(관측지점 클러스터·용량·신규 여부 균형, G1 용량 여유 1,000 kW 이상). 최적화를 하려면 최종 앙상블 OOF 잔차, 2개 이상 연도, 출발점은 학습용 반년만, 무작위 30회 평균±표준편차 기록, 다른 모델 잔차에서도 2σ 이상 우위일 때만 채택.
- 사용자는 "검증은 딱히 필요 없다"고 했다. 출발점 누수를 고친 재실행은 제안만 되고 결정되지 않았다.

### 2.3 "비용 무관 최대 성능" 기준으로 재정리 — 답변 완료

사용자: "이것은 대회라서 비용 상관없이 최대 성능을 이끌어 내야 한다." 이후 모든 권고의 기준.

- 앙상블: 넓고 깊게. 축 네 가지 — 분산(시드 5~10개×폴드 평균), 모델 계열(LightGBM·XGBoost·CatBoost, 행 단위 MLP, 하루 블록 NN), 입력(A만/B만/라운드 10만 모델), 결합(팀 합계 수준 L1·SMP×k 가중 스태킹, 반드시 OOF).
- **채택 규칙(전부에 적용):** 롤링 폴드(2022·2023·2024 각각 검증)의 SMP×k 가중 팀 합계 오차가 시드 편차 이상으로 줄어야만 채택.
- 구성: 천장 1.6%는 그대로. 쌍둥이(짝 맞춤) 분할을 기본으로 하고 조건부 잔차 최적화는 마지막에. 팀 크기 비대칭은 20,000 kW 하한 때문에 지렛대가 아니다.
- 비용과 별개로 남는 제약: 제출 총 20회·일 3회, 리더보드 공개 범위 미상, 평가 구간에 발전량·실측 기상 없음(자기회귀 피처 불가), GPU 없는 노트북, 마감 미상, 문제정의서 미공개.
- 기대 이득 순서: (1) 검증 하네스 + 실측 기상 입력 모델로 천장(예보 오차 몫) 측정 → (2) 단일 모델 강화(전체 기간, 라운드 10·17 동시 피처 + 불일치, A·B 불일치, 이웃 시각·하루 요약, site_id 범주형, 명판 대신 최근 1년 실효 출력 정규화[미검증]) → (3) NN 완성(하루 블록, L1, 임베딩, 노이즈 주입, 실측 기상 보조 출력, 다중 시드) → (4) 팀 합계 스태킹·중앙값 → (5) 후처리 → (6) 구성 → (7) 첫 제출은 베이스라인 그대로(형식·시간대·행 순서 기준점; 1시간 밀림이 모든 이득보다 큰 손실).

### 2.6 GNN + 미리 만든 엣지 가중치 — 답변 완료, 진행 여부 미결

- 허용(요약 규정 기준). 조건 세 가지: 엣지 재료는 제공 데이터만(거리·지점 공유·지점 거리·학습 잔차 상관) / 임베딩을 좌표로 해독하지 않음 / 엣지는 학습 구간 데이터로만(검증 누수 방지 + 17시 규칙).
- 효과의 한계: 평가 구간에 실측값이 없어 "이웃의 관측값 전파"가 불가. 역할은 예보의 공간 집계 + 발전소 특성 공유로 축소.
- 기대 이득: (a) 여러 관측지점 예보의 거리 가중 집계와 지점 간 불일치 신호(평가 구간 A 예보 결측 264행도 메움), (b) 신규 48개소 콜드스타트, (c) 팀 합계를 바로 출력해 SMP×k 가중 L1로 학습하는 그래프 수준 판독[가설; 표본이 400만 행→3만 5천 행으로 줄어 과적합 위험].
- **대조군 먼저:** 발전소별 최근접 지점 k개 예보의 거리 가중 평균·편차를 손 피처로 만들어 GBDT·MLP에 넣는 모델. 이것 없이는 GNN 이득이 그래프 덕인지 입력 증가 덕인지 구분 불가.
- 엣지 구성 권고: 후보는 거리 커널 + 지점 공유, 가중치는 태양 고도 효과를 뺀 잔차 상관으로 초기화 후 어텐션 학습, 1~2층, 모델이 바뀌면 재계산.

### 2.7 모델이 지형·눈 효과(대관령 눈, 산맥 차단)를 배우는가 — 답변 완료

- 모델은 기상학을 배우지 않고 "예보→발전량" 대응만 배운다. 지형 효과는 제공사의 수치예보가 이미 반영해 관측지점 예보로 들어온다.
- 구멍 세 가지: 예보는 지점 위치(발전소까지 5~15 km, 고도 차 가능) / 예보 오류(모델은 조건부 중앙값으로 헤지만 가능) / 고도 피처 없음(외부 지형 데이터 금지; **지점별 학습 기간 평균 지표기압이 고도 대용**, 제공 데이터라 허용. `wa_ground_press` 966~1039 hPa → 최고 지점 약 400 m, 대관령급 지점은 없을 듯).
- 발전소별 특수성을 배우는 조건: 사례 수(베이스라인 `min_child_samples=200`이 희귀 효과를 막음; 낮추면 잡음 증가, 검증으로 결정) / **변수가 입력에 있어야 함(베이스라인은 풍향·`wa_snow`·`wb_snow`·`wb_ice`·`wb_ceiling` 제외; 풍향은 sin·cos로)** / 비슷한 발전소끼리 증거 모으기(지점 평균 기압, 눈 빈도 같은 발전소별 고정 특성).
- 학습 구간에만 있는 실측 기상으로 "예보→실측" 지점별 버릇을 직접 학습 가능(README 다음 할 일 4번).
- **지금 피처로는 배울 수 없는 것: 눈 쌓임 지속 효과.** 입력이 전부 당 시각 예보라 어제 눈이 왔는지 모름. 해결은 지난 1~3일 예보로 만든 지연 피처(강설 합, 최저 기온, 마지막 눈 이후 0도 초과 누적 시간). 규칙상 안전(전날 예보는 그제 17시 발행).
- 중요한 이유: 큰 눈은 지방 전체에 동시에 와서 다음 날 수십 개소가 같은 방향으로 틀림 → 팀 합계에 그대로 남음. 겨울 SMP 높고 11~15시 k=3.
- 반대 근거: 국내 발전소 대부분 저지대라 고지대 효과 자체는 작을 수 있음. 눈 효과 크기는 데이터로 미확인.
- 환경이 되면 확인할 두 가지: 학습 기간 눈 예보 일수와 지점 분포 / 눈 예보 다음 날 실제 발전량이 예보 기반 기대치보다 얼마나 낮았는지.
