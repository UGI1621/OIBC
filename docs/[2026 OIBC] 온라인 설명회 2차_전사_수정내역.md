## 4. 확인이 필요한 항목 (미검증 또는 추정)

- **오믈레스타(후원사)**: 공고·대회 페이지에 후원사 명단이 없어 확인 불가. 전사 그대로 둠.
- **주관 "포스텍 OIBC와 솔라온케어"**: 전사는 "포스텍과 OIBC, 솔라원케어". OIBC는 포스텍 소속 센터로 보여 "포스텍 OIBC"로 묶음. 추정.
- **발언자 "H에너지 김민수 매니저"**, **운영진 "이슬아 선생님"**: 검증 수단 없음. 그대로 둠.
- **"전체 페널티의 약 81~82%"**: 2절 참고. 원 슬라이드 확인 필요.
- **"발전소별로 100kW부터 900kW"**: 전사 그대로 둠. 실제 `sites.csv`는 14.4~1,387.5 kW라 발언이 대략적이거나 오인식일 수 있음.
- **k=3 시간대 "10시부터 15시까지"**: 발언 그대로 둠. 데이터는 `ts` 기준 11~15시이며, 우측닫힘이므로 10:00~15:00 구간과 같은 뜻. 발언자도 "타임스탬프 기준"으로 유의하라고 당부함.
- **"한국 시간 기준으로 조정하게 됩니다"**: "적용하게 됩니다"로 다듬음. 원 발화 불명.
