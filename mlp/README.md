# mlp — 단일 MLP로 예측치 뽑기

`experiments/`와 별도로 돌아가는 최소 구성 MLP 프로젝트. 데이터 폴더는 읽기만 하고, 산출물은 전부 `mlp/outputs/`에 쓴다.

## 구성

| 파일 | 역할 |
|---|---|
| `common.py` | 경로, 데이터 로드, 피처(주최 측 `baseline.py`의 `features()` 재사용), `Scaler`(전처리), `MLP` 정의 |
| `train_small.py` | **공부용.** 작은 망 (128, 64) 단일 파일. 설정 블록 + 데이터 → 전처리 → 모델 → 학습 루프 → 테스트 → 저장 |
| `train_big.py` | **공부용 · 메인 모델.** 큰 망 (512, 512, 256), 임베딩 16, 드롭아웃 0.1, lr 1e-3. `train_small.py`와 뼈대가 같고 맨 위 CONFIG만 다름 |
| `train.py` | 실험용 통합 스크립트. `--hidden`, `--lr` 등 옵션, `--no-early-stop`(학습 곡선), `--seg-history`(에폭×구간 집계) |
| `eval_segments.py` | 테스트(홀드아웃 1년) 예측을 시각·월·용량·운량 구간별로 집계 → `segments.json` |
| `predict.py` | 저장된 모델로 대회 채점 구간 예측 → `composition.csv`, `forecast.csv`, `per_site_forecast.parquet`. 기본 모델은 `model_big_final_s0.pt` |

데이터 이름: 학습(train) / 검증(val, 조기 종료용 두 달) / 테스트(test, 홀드아웃 1년 2024-06~2025-05) / 대회 채점 구간(2025-06 이후, 실적 없음).

입력층 32차원(수치 24 + 발전소 임베딩 8)과 전처리 설명: artifact "OIBC MLP 입력층".

## 기본 설정

- 은닉층 (128, 64), ReLU, 드롭아웃 없음. 발전소 임베딩 8차원.
- 타깃 = 발전량 ÷ 설비용량 (0~1.2 clip). 주간(elev > 0) 행만 학습. 야간 예측은 0 고정.
- L1 손실, 배치 4096, AdamW lr 2e-3 (weight_decay 1e-5), 코사인 스케줄, 최대 40 에폭.
- 조기 종료: 학습 구간 끝 두 달을 시간순으로 떼어 MAE(kWh)가 6 에폭 연속 안 줄면 중단, 최적 에폭 가중치로 복원.
- 예보는 round 17만 사용. 학습 데이터는 2023-06-01 이후 (baseline과 동일).
- 전처리: 학습 행 통계로 NaN → 중앙값, z-score, ±6 clip. 통계는 모델 파일에 같이 저장되어 예측 때 그대로 적용.

## 실행

저장소 루트에서:

```
python mlp/train_big.py             # 테스트 점수 확인 (홀드아웃 1년)
python mlp/train_big.py --final     # 학습 구간 전체(조기 종료는 2025-04~05)로 제출용 모델 저장
python mlp/predict.py               # mlp/outputs/composition.csv, forecast.csv 생성
```

작은 망은 `train_small.py`로 같은 방식. 실험용 `train.py`는 `--mode val|final`, `--hidden 512,512,256 --emb 16 --drop 0.1 --lr 1e-3`, `--seed N`, `--round 10` 등을 받는다.
`predict.py --composition ref`는 주최 측 참조 배정(current_group)을 쓴다. 기본 `snake`는 용량 큰 순서로 G1, G2, G2, G1 반복 배정.

## 지금까지 결과 (테스트 = 홀드아웃 2024-06~2025-05)

| 모델 | 테스트 MAE (kWh) | 팀 합계 상대오차 | 최적 에폭 | 비고 |
|---|---|---|---|---|
| 작은 망 (128, 64), 시드 0 | 12.59 | 13.15% | 2 (사후 최저는 6에폭 12.37) | 에폭당 1초 |
| 큰 망 (512, 512, 256), 시드 0·1·2 | 12.25 / 12.14 / 12.09 (평균 12.16 ± 0.07) | 12.81 / 12.34 / 12.18% | 3 / 4 / 3 | 에폭당 11초(20스레드), 6스레드 병렬 시 ~15초 |
| **큰 망 3시드 예측 평균 (현재 제출)** | **11.91** | **12.14%** | 최종 모드 6 / 4 / 4 | 시드 간 오차 상관 0.966 |
| 참고: 기존 실험 V3 / V5 / GBDT / GBDT+NN | 12.31 / 12.12 / 12.26 / 11.78 | | | README(루트) 기록, 시드 1개 |

- 3시드 평균이 단일 시드 평균보다 0.25 kWh(2.1%) 좋다. 시드마다 틀리는 자리가 달라(상관 0.966) 평균하면 우연한 오차가 상쇄된다.
- 큰 망 시드 편차는 0.07로 README에 기록된 0.23보다 작다. 드롭아웃과 낮은 학습률(1e-3) 효과로 추정.
- 제출 파일은 최종 모드(학습 ~2025-03, 조기 종료 2025-04~05) 모델 3개의 이용률 평균. 예측 총량 60.2 GWh, 베이스라인(59.1)과 시간별 상관 0.995.
- 병렬 실행: `OMP_NUM_THREADS=6 python mlp/train_big.py --final --seed N &` 를 시드별로 띄우면 3개가 14분(순차 18분)에 끝난다. 메모리는 프로세스당 1.2~3 GB.
- 미해결: 검증 세트(두 달)가 작아 조기 종료가 흔들림. 다음 후보는 예보 오차 노이즈 주입, 3~8에폭 예측 평균, 용량 가중 손실, 시각·운량별 후처리 보정, GBDT와의 앙상블.
