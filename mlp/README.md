# mlp — 단일 MLP로 예측치 뽑기

`experiments/`와 별도로 돌아가는 최소 구성 MLP 프로젝트. 데이터 폴더는 읽기만 하고, 산출물은 전부 `mlp/outputs/`에 쓴다.

## 구성

| 파일 | 역할 |
|---|---|
| `common.py` | 경로, 데이터 로드, 피처(주최 측 `baseline.py`의 `features()` 재사용), `Scaler`(전처리), `MLP` 정의 |
| `train_small.py` | **공부용.** 작은 망 (128, 64) 단일 파일. 설정 블록 + 데이터 → 전처리 → 모델 → 학습 루프 → 테스트 → 저장 |
| `train_big.py` | **공부용 · 메인 모델.** 큰 망 (512, 512, 256), 임베딩 16, 드롭아웃 0.1, lr 1e-3. `train_small.py`와 뼈대가 같고 맨 위 CONFIG만 다름 |
| `train.py` | 실험용 통합 스크립트. `--hidden`, `--lr` 등 옵션, `--no-early-stop`(학습 곡선), `--seg-history`(에폭×구간 집계) |
| `eval_segments.py` | 테스트(홀드아웃 1년) 예측을 시각·월·용량·운량 구간별로 집계 → `segments.json` |
| `gbdt.py` | LightGBM 기준 모델(주최 측 600트리 설정, `--objective l1`). `--seeds 0-11`로 한 프로세스에서 여러 시드. 테스트·최종 예측을 parquet로 저장 |
| `eval_ensemble.py` | 테스트 모드 MLP 여러 개를 홀드아웃에서 각각·평균 채점. `--blend`로 GBDT 예측과 혼합 점수 |
| `eval_seeds.py` | 시드 k개 평균의 MAE 곡선(k=1..N), MLP·GBDT 혼합 가중치 탐색 → `seeds_test.json` |
| `predict.py` | 저장된 모델로 대회 채점 구간 예측 → `composition.csv`, `forecast.csv`, `per_site_forecast.parquet`. 기본은 `model_big_final_s*.pt` 전부 평균. `--gbdt 'gbdt_l1_final_pred*.parquet' --w-mlp 0.7`로 GBDT와 혼합 |

데이터 이름: 학습(train) / 검증(val, 조기 종료용 두 달) / 테스트(test, 홀드아웃 1년 2024-06~2025-05) / 대회 채점 구간(2025-06 이후, 실적 없음).

입력층 32차원(수치 24 + 발전소 임베딩 8)과 전처리 설명: artifact "OIBC MLP 입력층".

## 기본 설정

- 은닉층 (128, 64), ReLU, 드롭아웃 없음. 발전소 임베딩 8차원.
- 타깃 = 발전량 ÷ 설비용량 (0~1.2 clip). 주간(elev > 0) 행만 학습. 야간 예측은 0 고정.
- L1 손실, 배치 4096, AdamW lr 2e-3 (weight_decay 1e-5), 코사인 스케줄, 최대 40 에폭.
- 조기 종료: 학습 구간 끝 두 달을 시간순으로 떼어 MAE(kWh)가 6 에폭 연속 안 줄면 중단, 최적 에폭 가중치로 복원.
- 예보는 round 17만 사용. 학습 데이터는 2023-06-01 이후 (baseline과 동일).
- 전처리: 학습 행 통계로 NaN → 중앙값, z-score, ±6 clip. 통계는 모델 파일에 같이 저장되어 예측 때 그대로 적용.

## 실행

저장소 루트에서:

```
python mlp/train_big.py             # 테스트 점수 확인 (홀드아웃 1년)
python mlp/train_big.py --final     # 학습 구간 전체(조기 종료는 2025-04~05)로 제출용 모델 저장
python mlp/predict.py               # mlp/outputs/composition.csv, forecast.csv 생성
```

작은 망은 `train_small.py`로 같은 방식. 실험용 `train.py`는 `--mode val|final`, `--hidden 512,512,256 --emb 16 --drop 0.1 --lr 1e-3`, `--seed N`, `--round 10` 등을 받는다.
`predict.py --composition ref`는 주최 측 참조 배정(current_group)을 쓴다. 기본 `snake`는 용량 큰 순서로 G1, G2, G2, G1 반복 배정.

## 지금까지 결과 (테스트 = 홀드아웃 2024-06~2025-05)

| 모델 | 테스트 MAE (kWh) | 팀 합계 상대오차 | 비고 |
|---|---|---|---|
| 작은 망 (128, 64), 시드 0 | 12.59 | 13.15% | 최적 2에폭(사후 최저는 6에폭 12.37). 에폭당 1초 |
| 큰 망 (512, 512, 256), 시드 1개 | 12.18 ± 0.09 (12시드 범위 12.07~12.36) | | 최적 2~6에폭. 에폭당 11초(20스레드) |
| 큰 망 12시드 평균 | 11.85 | 12.06% | 시드 간 오차 상관 0.963 |
| **주최 측 baseline.py 방식** (600트리 L2, 라운드 10·17 평균), 시드 0 | **12.56** | **13.54%** | 모든 비교의 기준선. 라운드 17만 쓰면 12.66 / 13.41%, 라운드 10만 쓰면 12.88 / 14.10% |
| GBDT 600트리 L1, 시드 1개 | 12.25 ± 0.03 (12시드 범위 12.20~12.29) | | fit 12초. MLP보다 두 달 더 학습 |
| GBDT L1 12시드 평균 | 12.12 | 12.80% | 시드 간 오차 상관 0.985 |
| **MLP 12시드 0.7 + GBDT 12시드 0.3 (현재 제출)** | **11.68** | **11.85%** | MLP·GBDT 오차 상관 0.923. 0.6:0.4는 11.67 / 11.87% |
| 참고: 기존 실험 V3 / V5 / GBDT / GBDT+NN | 12.31 / 12.12 / 12.26 / 11.78 | | README(루트) 기록, 시드 1개 |

시드 k개 평균의 MAE (무작위 부분집합 40개 평균, `seeds_test.json`):

| k | 1 | 2 | 3 | 4 | 6 | 8 | 12 |
|---|---|---|---|---|---|---|---|
| MLP | 12.20 | 12.00 | 11.95 | 11.92 | 11.88 | 11.87 | 11.85 |
| GBDT | 12.25 | 12.18 | 12.16 | 12.15 | 12.14 | 12.13 | 12.12 |

- 시드 평균의 이득은 3개까지가 대부분이고(MLP −0.25, GBDT −0.09) 12개까지 늘려도 추가 −0.10 / −0.04다. GBDT는 시드 편차 자체가 작아 평균 이득도 작다.
- 혼합은 가중치 0.5~0.7 사이에서 거의 평평하다(11.67~11.68). 홀드아웃 한 해로 고른 값이라 0.7을 썼다.
- 손실 함수 선택이 트리 수보다 컸다. 같은 600트리에서 L2 12.66 → L1 12.25.
- 제출 파일은 최종 모드(학습 ~2025-03, 조기 종료 2025-04~05) MLP 12개 평균과 GBDT(학습 2023-06~2025-05) 12개 평균을 이용률 단위로 0.7:0.3 혼합. 예측 총량 59.9 GWh.
- 실행 시간: GBDT 12시드 테스트 2.5분 / 최종 5분. MLP 12시드는 3개씩 병렬(6스레드)로 테스트 10분 / 최종 29분. 메모리는 프로세스당 1.2~3 GB.
- 미해결: 검증 세트(두 달)가 작아 조기 종료가 흔들림(최적 에폭이 시드마다 2~6). 다음 후보는 예보 오차 노이즈 주입, 3~8에폭 예측 평균, 용량 가중 손실, 시각·운량별 후처리 보정.

## 검증 분할 (val 모드)

| 구간 | 용도 |
|---|---|

| 2024-04-01 ~ 2024-05-31 | 조기 종료 판단 |
| 2024-06-01 ~ 2025-05-31 | 검증. MAE(kWh/발전소·시간)와 팀 합계 상대오차 보고 |

final 모드는 2025-03-31까지 fit, 2025-04~05를 조기 종료용으로 쓴다.
