# OIBC 예측 모델 실험 기록

2026-10-16 기준. 팀원 공유용. 모든 점수는 같은 홀드아웃(2024-06 ~ 2025-05)에서 잰 값이라 서로 비교 가능하다.

## 1. 요약과 현재 제출

- **현재 제출**: 큰 MLP 12시드 평균 0.7 + GBDT(L1) 12시드 평균 0.3 혼합. 홀드아웃 **MAE 11.68 kWh, 팀 합계 상대오차 11.85%**.
- 출발점(작은 MLP 1개) 12.59에서 7.2% 내려왔다. 기여는 큰 망 −0.3, 시드 평균 −0.3, GBDT 혼합 −0.2 순.
- 인수인계 실험의 최고 기록(GBDT+NN 11.78, 시드 1개)을 넘었다.
- 구성(G1/G2)은 용량 큰 순서로 번갈아 배정하는 snake 분할. 구성 최적화는 아직 안 했다(기존 실험상 이득 1~2% 이내).

## 2. 공통 실험 조건

| 항목 | 내용 |
|---|---|
| 데이터 | 발전량 2023-06-01 이후, 예보 round 17(전일 17시 발행), 주간(태양고도 > 0)만 |
| 분할 (MLP) | 학습 2023-06 ~ 2024-03 (476,111행) / 검증·조기 종료 2024-04 ~ 05 (151,548행) / 테스트 2024-06 ~ 2025-05 (1,083,299행) |
| 분할 (GBDT) | 조기 종료가 필요 없어 학습 2023-06 ~ 2024-05 (627,659행), 테스트는 같음 |
| 지표 | MAE = 발전소·시간당 \|예측 − 실적\| 평균(kWh). 팀 합계 상대오차 = 시각별 253개소 합계의 \|예측 − 실적\| 합 ÷ 실적 합 |
| 입력 | 수치 24개(예보 A 6, 예보 B 9, 태양고도·방위·cosz·연중일 sin/cos·시각 6, 용량·위도·경도 3) + 발전소 임베딩 |
| 타깃 | 이용률 = 발전량 ÷ 설비용량, 0~1.2 clip. 야간은 학습 제외·예측 0 |
| 전처리 | 학습 행 통계로 NaN → 중앙값, 표준화, ±6 clip |
| 제출 파일 | 최종 모드(학습 ~2025-03, 조기 종료 2025-04 ~ 05) 모델로 2025-06 ~ 2026-05 예측 |

## 3. 시도한 것과 결과

성능 좋은 순. 큰 MLP = (512, 512, 256), 작은 MLP = (128, 64), GBDT = LightGBM 600트리.

| 순위 | 시도 | 테스트 MAE (kWh) | 팀 합계 상대오차 |
|---|---|---|---|
| 1 | 큰 MLP 12시드 + GBDT(L1) 12시드 혼합 0.7:0.3 (현재 제출) | 11.68 | 11.85% |
| 2 | 큰 MLP 12시드 평균 | 11.85 | 12.06% |
| 3 | 큰 MLP 3시드 평균 | 11.91 | 12.14% |
| 4 | GBDT(L1) 12시드 평균 | 12.12 | 12.80% |
| 5 | 큰 MLP 시드 1개 | 12.25 | 12.81% |
| 6 | GBDT(L1) 시드 1개 | 12.25 | 12.95% |
| 7 | 작은 MLP 시드 1개 | 12.59 | 13.15% |
| 8 | GBDT 주최 측 설정 그대로 (L2) | 12.66 | 13.41% |

인수인계 실험(experiments/)의 최고 기록은 GBDT+NN 5:5 혼합 11.78 (시드 1개). 세부 설정과 시드별 수치는 `mlp/README.md`와 `mlp/outputs/seeds_test.json`에 있다.

**L1과 L2는 손실 함수, 즉 "틀린 만큼을 어떻게 벌점으로 바꾸느냐"의 두 방식이다.** L1은 틀린 크기를 그대로 더한다(10 틀리면 10, 20 틀리면 20). L2는 제곱해서 더한다(10 틀리면 100, 20 틀리면 400). L2는 크게 틀린 날을 훨씬 미워해서 그걸 줄이려고 평소 예측을 희생하고, L1은 평범한 날 대부분을 잘 맞히는 쪽으로 간다. 이 대회의 벌금은 |예측 − 실적|에 비례해 20 틀리면 10 틀린 것의 정확히 2배이므로 L1이 벌금 모양과 맞다. 같은 GBDT 600트리에서 L2 12.66, L1 12.25로 손실 함수 하나가 3.2% 차이를 냈고, 주최 측 베이스라인은 LightGBM 기본값인 L2를 그대로 쓰고 있다. MLP는 처음부터 L1(`nn.L1Loss`)로 학습했다.

## 4. 구간별 진단 (작은 MLP 기준, 큰 MLP에서 재확인 필요)

| 축 | 관찰 | 뜻 |
|---|---|---|
| 시각 | 벌금의 82%가 11~15시(k=3)에서 발생. 이 구간 +3~5% 과대예측. 17~20시는 −7 ~ −41% 과소, 6시는 +30% 과대 | 한낮 편향이 벌금에 3배로 들어감. 시각별 보정이 가장 싼 개선 |
| 운량(예보 A) | 맑음 +5.7%, 구름조금 +5.8%, 흐림 −4.9%. 에폭을 바꿔도 그대로 | 운량-발전 관계를 실제보다 완만하게 배움. 구조적 편향 |
| 용량 | 이용률 기준 MAE는 7.4~8.1%로 크기와 무관. 700kW 이상 13곳이 kWh 오차의 30%, +5.2% 과대 | 큰 발전소 개별 보정과 kWh 가중 손실의 근거 |
| 월 | 2024-07 −10.8%(장마), 2025-01 +7.7%. 8·12·3월이 가장 좋음(10~11%) | 계절별 편향 존재 |

## 5. 배운 것

1. **손실은 L1.** 벌금이 \|예측 − 실적\|에 비례하므로 L1이 정렬된다. 같은 GBDT에서 L2 → L1이 3.2% 차이로, 트리 수나 망 크기보다 큰 효과였다.
2. **조기 종료는 필수지만 지금 검증 세트(두 달)로는 운에 좌우된다.** 에폭마다 ±0.3 흔들려 최적 에폭이 시드마다 2~6으로 달라진다. 테스트 기준 최적과의 차이가 0.2 수준이다.
3. **시드 평균은 3개까지가 핵심.** MLP는 3개에서 −2.1%, 12개에서 −2.7%. GBDT는 편차가 작아 −0.7% / −1.0%.
4. **서로 다른 모델을 섞는 게 시드를 늘리는 것보다 낫다.** MLP·GBDT 오차 상관 0.923은 같은 모델 시드 간(0.963, 0.985)보다 낮다. 혼합 이득 −0.17이 시드 9개 추가 −0.10보다 크다.
5. **남은 오차의 상당 부분은 구조적 편향이다.** 시각·운량·큰 발전소 편향은 학습을 더 해도 사라지지 않았다. 후처리 보정의 대상이다.
6. **시간**: GBDT 600트리 12초(테스트) / 25초(최종). 큰 MLP는 테스트 2분, 최종 10분(6스레드 병렬 3개 기준). 12시드 전체 체인 49분.

## 6. 다음 할 일 (우선순위)

1. 시각·운량·큰 발전소 편향 보정. 홀드아웃에서 계수를 구해 후처리로 적용. 큰 MLP 기준으로 진단 재확인부터.
2. 예보 오차 노이즈 주입(학습 중 기상 입력에 예보−실측 표준편차 크기의 노이즈). 인수인계 실험에서 −2%와 시드 편차 소멸.
3. 조기 종료 안정화: 3~8에폭 예측 평균 또는 검증 세트를 넉 달 이상으로.
4. 손실에 용량(×SMP×k) 가중. 손실을 채점 기준과 정렬.
5. 시간 문맥 피처(t±1, 하루 요약), 관측지점 임베딩, round 10 예보 추가.
6. 검증 하네스: 롤링 폴드(검증 연도 2022·2023·2024), 벌금 지표, 시드 3개 기본.

## 7. 재현 방법

저장소 루트에서. 데이터 폴더는 README(루트) 안내대로 둔다.

```
python mlp/train_big.py --seed 0            # 테스트 점수 (시드별)
python mlp/train_big.py --final --seed 0    # 제출용 모델
python mlp/gbdt.py --objective l1 --seeds 0-11            # GBDT 테스트 12시드
python mlp/gbdt.py --objective l1 --seeds 0-11 --final    # GBDT 최종 12시드
python mlp/eval_seeds.py                    # 시드 곡선 + 혼합 가중치 → mlp/outputs/seeds_test.json
python mlp/predict.py --gbdt 'gbdt_l1_final_pred*.parquet' --w-mlp 0.7   # 제출 파일
```

병렬: `OMP_NUM_THREADS=6 python mlp/train_big.py --seed N &`를 3개씩. 메모리는 프로세스당 1.2~3 GB.

| 파일 | 내용 |
|---|---|
| `mlp/README.md` | 프로젝트 구성, 설정, 결과표 |
| `mlp/train_small.py`, `mlp/train_big.py` | 공부용 단일 파일. 하이퍼파라미터마다 주석 |
| `mlp/outputs/seeds_test.json` | 시드별 점수, k 곡선, 혼합 가중치별 점수 |
| `mlp/outputs/segments.json` | 구간별 진단 수치 |
| `mlp/outputs/history_*.json` | 에폭별 학습 곡선 |
| `mlp/outputs/forecast.csv`, `composition.csv` | 현재 제출 파일 |
