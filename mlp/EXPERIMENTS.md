# OIBC 예측 모델 실험 기록

2026-10-16 기준. 팀원 공유용. 모든 점수는 같은 홀드아웃(2024-06 ~ 2025-05)에서 잰 값이라 서로 비교 가능하다.

## 1. 요약과 현재 제출

- **현재 제출**: 큰 MLP 12시드 평균 0.7 + GBDT(L1) 12시드 평균 0.3 혼합. 홀드아웃 **MAE 11.68 kWh, 팀 합계 상대오차 11.85%**.
- **기준선**은 주최 측 baseline.py 설정(LightGBM 600트리, L2 손실, 예보 라운드 10·17 모델 평균)을 같은 홀드아웃에서 잰 값으로, MAE 12.56 kWh / 팀 합계 13.54%다. 아래 모든 비교는 이 값 기준이다.
- 기준선 대비 현재 제출은 MAE −0.88 kWh(−7.0%), 팀 합계 상대오차 −1.7%p. 기여는 손실 L1 전환 −0.3, 큰 MLP −0.3, 시드 평균 −0.3, GBDT 혼합 −0.2 순(겹치는 부분이 있어 합은 −0.88).
- 인수인계 실험의 최고 기록(GBDT+NN 11.78, 시드 1개)을 넘었다.
- 구성(G1/G2)은 용량 큰 순서로 번갈아 배정하는 snake 분할. 구성 최적화는 아직 안 했다(기존 실험상 이득 1~2% 이내).

## 3. 시도한 것과 결과

성능 좋은 순. 기준선은 주최 측 baseline.py 방식. 큰 MLP = (512, 512, 256), 작은 MLP = (128, 64), GBDT = LightGBM 600트리.

| 순위 | 시도 | 테스트 MAE (kWh) | 베이스라인 대비 | 팀 합계 상대오차 |
|---|---|---|---|---|
| 1 | 큰 MLP 12시드 + GBDT(L1) 12시드 혼합 0.7:0.3 (현재 제출) | 11.68 | −7.0% | 11.85% |
| 2 | 큰 MLP 12시드 평균 | 11.85 | −5.7% | 12.06% |
| 3 | 큰 MLP 3시드 평균 | 11.91 | −5.2% | 12.14% |
| 4 | GBDT(L1) 12시드 평균 | 12.12 | −3.5% | 12.80% |
| 5 | 큰 MLP 시드 1개 | 12.25 | −2.5% | 12.81% |
| 6 | GBDT(L1) 시드 1개 | 12.25 | −2.5% | 12.95% |
| 7 | 주최 측 베이스라인 (GBDT 600트리, L2, 라운드 10·17 평균) | 12.56 | 0 (기준) | 13.54% |
| 8 | 작은 MLP 시드 1개 | 12.59 | +0.2% | 13.15% |

**표의 숫자 읽는 법**
- **테스트 MAE**: 발전소 하나·한 시각 단위로 |예측 − 실적|을 kWh로 재서 평균한 값. 발전소끼리 반대로 틀려도 서로 지워지지 않는다. 모델 품질 지표.
- **팀 합계 상대오차**: 시각마다 253개소 예측을 다 더한 뒤 |합계 예측 − 합계 실적|을 구해 1년치를 더하고, 총 발전량으로 나눈 비율. 발전소끼리 반대로 틀린 건 지워진다. 대회 벌금이 집합 합계 오차로 매겨지므로 벌금에 더 가까운 지표. 단, SMP·k 가중은 없다.
- **베이스라인 대비**: MAE 기준 상대 변화, (모델 MAE − 12.56) ÷ 12.56. 팀 합계는 이미 퍼센트라 이 열에 넣지 않았고, 요약에 13.54% → 11.85%(−1.7%p)로 따로 적었다.
- **베이스라인**: 주최 측 baseline.py 설정(LightGBM 600트리, L2, 라운드 10·17 평균)을 우리 홀드아웃 분할(학습 2023-06 ~ 2024-05, 테스트 2024-06 ~ 2025-05)에 그대로 적용한 점수. 리더보드 점수가 아니다. 리더보드는 SMP·k 가중 벌금이라 여기서의 −7.0%가 그대로 옮겨가지는 않고, 방향과 대략의 크기만 믿는다.

인수인계 실험(experiments/)의 최고 기록은 GBDT+NN 5:5 혼합 11.78 (시드 1개). 세부 설정과 시드별 수치는 `mlp/README.md`와 `mlp/outputs/seeds_test.json`에 있다.

**L1과 L2는 손실 함수, 즉 "틀린 만큼을 어떻게 벌점으로 바꾸느냐"의 두 방식이다.** L1은 틀린 크기를 그대로 더한다(10 틀리면 10, 20 틀리면 20). L2는 제곱해서 더한다(10 틀리면 100, 20 틀리면 400). L2는 크게 틀린 날을 훨씬 미워해서 그걸 줄이려고 평소 예측을 희생하고, L1은 평범한 날 대부분을 잘 맞히는 쪽으로 간다. 이 대회의 벌금은 |예측 − 실적|에 비례해 20 틀리면 10 틀린 것의 정확히 2배이므로 L1이 벌금 모양과 맞다. 같은 GBDT 600트리에서 L2 12.66, L1 12.25로 손실 함수 하나가 3.2% 차이를 냈고, 주최 측 베이스라인은 LightGBM 기본값인 L2를 그대로 쓰고 있다. MLP는 처음부터 L1(`nn.L1Loss`)로 학습했다.

## 4. 구간별 진단 (작은 MLP 기준, 큰 MLP에서 재확인 필요)

| 축 | 관찰 | 뜻 |
|---|---|---|
| 시각 | 벌금의 82%가 11~15시(k=3)에서 발생. 이 구간 +3~5% 과대예측. 17~20시는 −7 ~ −41% 과소, 6시는 +30% 과대 | 한낮 편향이 벌금에 3배로 들어감. 시각별 보정이 가장 싼 개선 |
| 운량(예보 A) | 맑음 +5.7%, 구름조금 +5.8%, 흐림 −4.9%. 에폭을 바꿔도 그대로 | 운량-발전 관계를 실제보다 완만하게 배움. 구조적 편향 |
| 용량 | 이용률 기준 MAE는 7.4~8.1%로 크기와 무관. 700kW 이상 13곳이 kWh 오차의 30%, +5.2% 과대 | 큰 발전소 개별 보정과 kWh 가중 손실의 근거 |
| 월 | 2024-07 −10.8%(장마), 2025-01 +7.7%. 8·12·3월이 가장 좋음(10~11%) | 계절별 편향 존재 |

## 5. 배운 것

1. **손실은 L1.** 벌금이 \|예측 − 실적\|에 비례하므로 L1이 정렬된다. 같은 GBDT에서 L2 → L1이 3.2% 차이로, 트리 수나 망 크기보다 큰 효과였다.
2. **조기 종료는 필수지만 지금 검증 세트(두 달)로는 운에 좌우된다.** 에폭마다 ±0.3 흔들려 최적 에폭이 시드마다 2~6으로 달라진다. 테스트 기준 최적과의 차이가 0.2 수준이다.
3. **시드 평균은 3개까지가 핵심.** MLP는 3개에서 −2.1%, 12개에서 −2.7%. GBDT는 편차가 작아 −0.7% / −1.0%.
4. **서로 다른 모델을 섞는 게 시드를 늘리는 것보다 낫다.** MLP·GBDT 오차 상관 0.923은 같은 모델 시드 간(0.963, 0.985)보다 낮다. 혼합 이득 −0.17이 시드 9개 추가 −0.10보다 크다.
5. **남은 오차의 상당 부분은 구조적 편향이다.** 시각·운량·큰 발전소 편향은 학습을 더 해도 사라지지 않았다. 후처리 보정의 대상이다.
6. **시간**: GBDT 600트리 12초(테스트) / 25초(최종). 큰 MLP는 테스트 2분, 최종 10분(6스레드 병렬 3개 기준). 12시드 전체 체인 49분.

## 8. 2026-10-28 벌금 기준 실험 (에폭 평균, 라운드 변화)

자세한 사고 흐름은 [docs/2026-10-28-penalty-analysis.md](../docs/2026-10-28-penalty-analysis.md). 여기서부터는 MAE 대신 **대회 점수식 벌금**(0.1 × SMP × k × |팀 합계 오차|, snake 구성)으로 비교한다. 채점은 `mlp/eval_penalty.py`.

| 모델 (시드 3개 평균) | 홀드아웃 벌금 | 기존 혼합 대비 |
|---|---|---|
| 주최 측 베이스라인 (L2, 라운드 10·17 평균) | 230.2백만 원 | +14.4% |
| GBDT L1 | 217.1백만 원 | |
| GBDT L1 + 라운드 변화 | 214.9백만 원 | |
| 큰 MLP, 검증 최저 에폭 하나 (기존) | 204.5백만 원 | |
| 큰 MLP, 16에폭 예측 평균 | 200.1백만 원 | |
| 혼합 0.7/0.3, 기존 | 201.3백만 원 | 0 (기준) |
| **혼합 0.7/0.3, MLP 에폭 평균 + GBDT 라운드 변화** | **196.5백만 원** | **−2.4%** |

- **에폭 평균:** 같은 시드에서도 홀드아웃 벌금이 한 에폭마다 ±2,000만 원 출렁였고, 검증 MAE와 벌금의 상관은 0.16~0.23이었다. 그래서 에폭 하나를 고르지 않고 16에폭 예측을 평균한다. 5절 2번의 "조기 종료가 운에 좌우된다"를 벌금 기준으로 확인한 것이다.
- **라운드 변화:** 같은 시각 예보의 라운드 17 − 라운드 10 값 5개(A 구름·강수, B 구름·강수확률·강수량)다. GBDT 는 3시드 모두 벌금이 줄었다(평균 −1.0%). 예보가 바뀐 시간대에서 "바뀐 예보를 다 믿지 않는" 패턴을 배운다. MLP 에 넣으면 에폭 평균 후에도 조금 나빠져서 MLP 에는 넣지 않았다.
- **효과 없던 것:** 두 예보 회사의 차이 입력(0%), 실측 날씨로 학습(+14%), 계절·시각 편향 사후 보정(상한 0%).
- **예보 오차 몫:** 입력을 실측 날씨로 바꾸면 벌금이 −31%다. 나머지 약 2/3는 날씨 예보를 고쳐도 남는다.
- **주의:** 같은 홀드아웃을 보며 방법을 골랐다. 실제 효과는 조금 작을 수 있다.

## 9. 2026-10-29 학습 시작일, 안 쓰던 예보 열

8절과 같은 벌금 채점(시드 3개, 단위 백만 원). 같은 시드끼리 비교해 시드 흔들림과 구분했다.
시드 3개 요약은 두 방식이 있다. ① 시드별 벌금의 평균, ② 시드 평균 예측의 벌금(eval_penalty.py 방식, ①보다 조금 낮다).
아래 GBDT 행은 ①, MLP·혼합 행은 ②다. 같은 표의 같은 종류끼리만 비교한다.
