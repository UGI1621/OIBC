# OIBC 2026 — 태양광 집합자원 구성·예측

2026 POSTECH OIBC Big Data Challenge (제6회 POSTECH·KAIST·UNIST AI & 데이터사이언스 경진대회) 참가 작업 공간.
태양광 발전소 253개소를 두 집합자원 G1·G2로 나누고, 평가 기간 1년(2025-06-01 ~ 2026-06-01)의 집합별 시간별 발전량을 하루 전 예측으로 제출한다.

## 전달 사항 (2026-10-08)

- **점수는 벌금만으로 갈린다.** 점수식 `S = Σ SMP·실적 − 0.10·Σ SMP·k·|예측 − 실적|`에서 앞 항은 전체 실적 합이라 누가 해도 같다. 목표는 **SMP×k 가중 절대오차(팀 합계 기준) 최소화**다. k는 11~15시 3, 그 외 1.
- **구성(팀 나누기)은 "지역으로 가르지 말고 섞는다"로 사실상 끝.** 지역 분할은 벌금 +8~12%, 무작위로 섞으면 이론 하한에 +1.6%, 최적화해도 +1.3%(검증 기준). 노력은 예측에 쓴다.
- **검증은 반드시 시간 분할.** 무작위 행 분할은 점수를 26% 낙관적으로 보고한다. 비교는 시드 3개 이상 평균으로.
- **손실은 MAE(L1).** MSE 대비 오차 3~4% 감소. SMP×k는 마지막에 샘플 가중치로 넣는다.
- **가장 큰 이득은 GBDT + 신경망 앙상블.** 팀 합계 오차 12.89% → 11.88%(−7.8%). 신경망은 L1 손실·발전소 임베딩·시간순 조기종료·예보오차 노이즈 주입이 있어야 GBDT와 비슷해진다.
- **규정:** 외부 데이터와 외부 데이터로 사전학습된 모델 금지, 예측시점(전일 17시) 이후 정보 금지, 좌표로 발전소 특정 금지, 제출은 일 3회·총 20회. 공식 문제정의서는 아직 미공개.

| 경로 | 내용 |

| `requirements.txt` | 파이썬 의존성 |

**저장소에 없는 것:** 대회 원본 데이터(`OIBC_2026_DATA/`), zip, DuckDB 파일, parquet. 재배포 금지·용량 문제로 `.gitignore`에 넣었다.

## 시작하기

1. 주최 측 데이터 zip을 받아 풀어서 아래 경로가 되게 둔다 (스크립트들이 이 경로를 가정한다).
   ```
   OIBC_2026_DATA/handover 2/01_participant_dataset/
     README.md  baseline.py  sites.csv  smp.csv  train/  test/
   ```
2. 설치: `pip install -r requirements.txt` (torch는 CPU 빌드로: `pip install torch --index-url https://download.pytorch.org/whl/cpu`). Python 3.13, LightGBM 4.7, DuckDB 1.5, torch 2.12에서 확인.
3. 조회용 DB 생성(약 10초, 700MB): `python build_db.py` → 사용법은 `DB_README.md`.
4. 베이스라인 재현(약 75초): 데이터 폴더에서 `python baseline.py --sites-out baseline_sites.parquet` → `composition.csv`, `forecast.csv` 생성.
5. 실험 스크립트는 데이터 폴더를 작업 디렉터리로 두고 실행한다 (주최 측 `baseline.py`의 피처 함수를 import 하기 때문).
   ```
   cd "OIBC_2026_DATA/handover 2/01_participant_dataset"
   python ../../../experiments/split_experiment.py
   ```

## 지금까지 확인된 것

모두 학습 구간 마지막 1년(2024-06 ~ 2025-05)을 검증으로 뗀 시간 분할 결과. 모델은 LightGBM(300 trees) 또는 작은 MLP, round 17 예보, 베이스라인 피처. 수치는 발전소·시간당 MAE(kWh)와 팀 합계 상대오차.

| 주제 | 결과 | 스크립트 |
|---|---|---|
| 검증 분할 | 무작위 행 분할 MAE 0.0565 vs 시간 분할 0.0766(이용률). 무작위 날 분할 0.0738 | `split_experiment.py` |
| 손실함수 | L2 → L1: 이용률 MAE 0.0766 → 0.0737, 합계 오차 13.31% → 12.89% | `split_experiment.py` |
| 구성 | 한 팀 하한 2.146억 / 참조 A·B +2.2% / 동서 +7.9% / 남북 +11.8% / 무작위 섞기 +1.6% / 최적화(OOS) +1.3%. 두 팀 오차 상관은 섞기만 해도 0.93 | `comp_experiment.py` |
| 앙상블 | GBDT끼리 오차 상관 0.92~0.98, GBDT–NN 0.82~0.88. 5모델 평균 합계 오차 12.83% → 12.37%. GBDT+NN(개선판) 50:50 → MAE 11.78, 합계 11.88% | `ensemble_experiment.py`, `mlp_ablation.py` |
| 신경망이 약했던 이유 | 복제 14.08 → 조기종료·전체데이터 13.00 → L1 12.66 → 발전소 임베딩 12.31 → 큰 네트워크 12.12 (GBDT 12.26). 손 피처 가공은 효과 없음 | `mlp_ablation.py` |
| 가상 데이터 | 예보오차 모사 노이즈 주입(3시드): 12.45 → 12.18, 합계 12.63% → 12.04%, 시드 편차 거의 소멸. 실측 기상을 입력으로 쓴 행 추가는 GBDT에도 유효(12.26 → 12.17). 가짜 레이블은 효과 불분명, GBDT 노이즈 복제는 해로움 | `synth_experiment.py`, `synth_seeds.py` |
| 시드 잡음 | 같은 설정의 NN이 시드만으로 최대 0.23 kWh 차이. 0.3 이하 차이는 단일 시드로 판단 금지 | `synth_seeds.py` |

데이터 사실: 평가 기간 벌금 가중치의 44.7%가 11~15시에 있고 발전량의 65.5%가 그 구간. SMP 0원 시각 18개(벌금 0). 48개소는 2024-06 이후에야 데이터 시작. 기본 모델의 벌금은 매출의 약 2.9%.

## 다음 할 일

1. 검증 하네스 고정: 롤링 폴드(2022·2023·2024 각각 검증), 팀 합계 기준 SMP×k 가중 MAE, 시드 3개 평균.
2. GBDT 튜닝: objective l1, early stopping, round 10·17 모두, 전체 학습 기간, 같은 날 이웃 시각 예보·하루 요약 피처, site_id 범주형.
3. 신경망 하루 블록 모델: 입력 대상일 24시간 × 예보, L1 손실, 발전소 임베딩, 예보오차 노이즈 주입, 실측 기상 보조 출력(multi-task).
4. 2단계/스태킹: 1단계(예보 → 실측 기상) 예측은 out-of-fold로 만들어 2단계 피처로 추가.
5. 분위 예측 + 발전소 간 오차 상관으로 시나리오 생성 → 시각별 팀 합계 **중앙값** 제출. 구성 최적화도 시나리오 위에서.
6. 후처리(야간 0, 상한, 시각별 편향 보정) → 앙상블 가중치는 홀드아웃에서 → 마지막에 SMP×k 가중 적용.
7. 제출 전략: 첫 제출은 베이스라인으로 기준점, 이후 한 번에 하나씩 변경. 리더보드로 튜닝하지 않는다.

## 미확인 사항 (문제정의서 공개 후 확인)

- 점수식 세부, 동점 처리, 제출 무효 조건, 리더보드 공개 방식(public/private 여부).
- 평가 기간 SMP를 예측 입력으로 쓰는 것이 허용되는지 (가중치 용도는 명백히 허용). 현재는 입력으로 쓰지 않는 쪽을 권장.
- 20,000 kW 요건의 출처, 평가 시 결측 실적 처리 방식.
